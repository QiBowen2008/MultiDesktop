# 2026-07-30 工作日志

## WinGet 自动验证失败诊断 (0xC0000409)

### 问题
AOT 编译的 MultiDesktop.exe 上传 WinGet 后，自动验证返回退出码 -1073740791 (0xC0000409 = STATUS_STACK_BUFFER_OVERRUN)。用户反馈"本机一切正常，WinGet 上传就不行"。

### 根因
`DataTable.ReadXml` / `DataTable.WriteXml(WriteSchema)` 在 NativeAOT 下必然崩溃。

崩溃路径：
1. WinGet 验证运行 `MultiDesktop.exe`（无参数）→ GUI 模式
2. `Program.cs:100-113` 检查 `AppSettings.xml` 是否存在
3. 无论走哪个分支都会调用 `WriteXml(WriteSchema)` 或 `ReadXml()`
4. AOT runtimeconfig 中 `System.Data.DataSet.XmlSerializationIsSupported = false`
5. 抛出 `PlatformNotSupportedException` → FailFast → 0xC0000409

### 为什么本机正常
AOT 构建的 `runtimeconfig.json` 明确设置了：
- `System.Data.DataSet.XmlSerializationIsSupported = false`
- `System.Runtime.CompilerServices.RuntimeFeature.IsDynamicCodeSupported = false`
- `System.Text.Json.JsonSerializer.IsReflectionEnabledByDefault = false`
- `System.Windows.Forms.Binding.IsSupported = false`

这些特性开关在编译时固化，任何机器上运行 AOT 构建都会崩溃。本机"正常"的原因最可能是：
1. 本机测试的是 JIT 构建（MultiDesktop.csproj → bin/Debug 或 bin/Release），JIT 支持动态代码
2. 或仅测试了 CLI 命令（--version / --help / --ListDesktop），这些路径在 ReadXml 之前 return

### 受影响的调用点（共 8 处）
- `Program.cs:108` — WriteXml("AppSettings.xml", WriteSchema) — 初始化时
- `Program.cs:112` — ReadXml("AppSettings.xml") — 启动时
- `Program.cs:70` — WriteXml("DesktopList.xml", WriteSchema) — CLI --DeleteDesktop
- `Program.cs:172` — ReadXml("DesktopList.xml") — CLI InitDesktopListForCli
- `frmMain.cs:13` — ReadXml("DesktopList.xml") — 主窗体加载
- `frmMain.cs:61` — WriteXml("DesktopList.xml", WriteSchema) — 删除桌面
- `frmAddDesktop.cs`(via DesktopManager.AddDesktop) — WriteXml — 添加/编辑桌面
- `frmSet.cs:24` — WriteXml("AppSettings.xml", WriteSchema) — 保存设置
- `frmClose.cs:17,29` — WriteXml("AppSettings.xml", WriteSchema) — 退出

### 修复方案
用 System.Text.Json + JsonSerializerContext (source generator) 替换所有 DataTable XML 序列化。
保留 DataTable 作为内存数据结构（用于 AntdUI.Table 数据绑定），仅替换持久化层。

### 关键文件
- AOT 构建配置: `src/MultiDesktop/MultiDesktop.AOT.csproj` (PublishAot=true, _SuppressWinFormsTrimError=true)
- AOT runtimeconfig: `src/MultiDesktop/bin/ReleaseAOT/net10.0-windows/win-x86/MultiDesktop.AOT.runtimeconfig.json`
