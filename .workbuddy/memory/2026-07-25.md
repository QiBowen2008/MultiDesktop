# 2026-07-25 工作日志

## MultiDesktop AOT 问题分析

对项目进行了完整的 Native AOT 编译分析（`dotnet publish MultiDesktop.AOT.csproj -c ReleaseAOT -r win-x86`）。

### 发现的问题

**P0 严重 — DataTable XML 序列化 (IL3050 × 8)**
- `DataTable.ReadXml()` 和 `DataTable.WriteXml(XmlWriteMode.WriteSchema)` 内部使用 XmlSerializer，需要动态代码生成
- 影响 8 处调用：Program.cs:32,36 / frmMain.cs:13,57 / frmAddDesktop.cs:29 / frmSet.cs:24 / frmClose.cs:17,29
- AOT 编译后运行时必然崩溃
- 修复方案：替换为 System.Text.Json + 强类型数据模型

**P1 警告 — 程序集级 AOT 警告 (IL3053 × 6)**
- AntdUI.dll（第三方 UI 库内部使用反射）
- System.Windows.Forms.dll / Primitives（框架级）
- System.ComponentModel.TypeConverter.dll（类型转换器依赖反射）

**P1 警告 — _SuppressWinFormsTrimError=true 掩盖修剪错误**
- ComponentResourceManager.ApplyResources 依赖反射设置控件属性

**P2 次要 — IL3000 Assembly.Location 返回空字符串**
- WinForms 框架内部问题，项目代码无需修改

**P3 代码质量 — 9 处 Nullable 警告 (CS8601/8602/8604)**

### 项目结构
- 标准项目: `MultiDesktop.csproj`（引用 MultiLangDll.dll）
