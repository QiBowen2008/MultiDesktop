## 修复 winget 云端验证崩溃（0xC0000409）

- 现象：winget 验证运行 MultiDesktop.exe 返回 -1073740791 (0xC0000409 STATUS_STACK_BUFFER_OVERRUN)。
- 根因：**NativeAOT 下任何未处理异常都会 fail-fast 成 0xC0000409**。真实异常是
  `UnauthorizedAccessException`——程序把 AppSettings.xml/DesktopList.xml 写到**当前工作目录(CWD)**，
  验证环境 CWD 不可写。用"只读 CWD 运行 exe"在本地完整复现了相同退出码。
- 顺带发现第二处 CWD 依赖：托盘图标 `new Icon("Desktop.ico")`（frmMain.Designer.cs）。
- 修复（已重新 AOT 发布 win-x86 并验证）：
  1. Program.cs 新增 `AppPaths` 静态类：配置文件统一放 exe 目录（探测可写），不可写回退 %AppData%\MultiDesktop。
  2. 4 个文件共 15 处 `"AppSettings.xml"`/`"DesktopList.xml"` 字面量替换为 `AppPaths.*`。
  3. Main 包 try/catch，异常写 error.log + 弹窗，不再 fail-fast。
  4. 托盘图标改为 `Path.Combine(AppContext.BaseDirectory, "Desktop.ico")`。
  5. 3 处 `Process.GetCurrentProcess().Kill()` 改为 `Environment.Exit(0)`（Kill 退出码是 -1，winget 可能判非零失败）。
- 验证：只读 CWD 下启动不再崩溃、CLI `--version` 正常、无 error.log。
- 待办提醒：重新提交 winget 前需更新清单里的 InstallerSha256（二进制已变）。
- 经验：**.NET NativeAOT 程序排查 0xC0000409 = 查未处理异常**，先换 CWD/降权限跑一遍；GUI 程序不要依赖 CWD。
