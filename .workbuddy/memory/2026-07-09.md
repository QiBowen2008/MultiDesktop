# 2026-07-09 工作日志

## C# → Lazarus/Delphi 项目迁移

将 MultiDesktop 项目从 C# WinForms (.NET 4.0) 完整迁移为 Lazarus/Object Pascal 项目。

### 迁移文件清单
| C# 原文件 | Lazarus 目标文件 |
|---|---|
| Program.cs | MultiDesktop.lpr + DesktopSwitcher.pas |
| Models/DesktopConfig.cs | DesktopConfig.pas |
| Services/JsonConfigManager.cs | JsonConfigManager.pas |
| frmLauncher.cs + Designer | LauncherFormUnit.pas + .lfm |
| frmMain.cs + Designer | MainFormUnit.pas + .lfm |
| MultiDesktop.csproj | MultiDesktop.lpi |

### 关键技术映射
- JSON: System.Web.Script.Serialization → fpjson 单元
- 注册表: Microsoft.Win32.Registry → TRegistry (Registry 单元)
- 进程: Process → TProcess
- 布局: SplitContainer → TPanel + TSplitter + TPanel (Align)
- 对话框: FolderBrowserDialog → TSelectDirectoryDialog
- DPI: SetProcessDPIAware → Application.Scaled + Lazarus 自带处理
- 窗体生命周期: Load → OnCreate

### 架构决策
- 全局状态 (AppState) → DesktopSwitcher.pas 中的全局变量 (CurrentConfig, ConfigPath, SelectedDesktopIndex)
- 配置管理 → 类方法 (class function) 实现，线程安全 (TCriticalSection)
- 单元引用通过 implementation 节 uses 解决循环引用问题
