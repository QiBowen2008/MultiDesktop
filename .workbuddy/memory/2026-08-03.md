### Git 远程连接诊断与修复
- **问题**：`git fetch` 声称成功但 `.git/refs/remotes/origin/` 为空，远程引用不落盘
- **根因**：Git 2.54.0 (PortableGit) bug —— fetch 通信正常、FETCH_HEAD 数据完整，但 ref 文件不写入磁盘
- **修复**：从 FETCH_HEAD 提取 commit hash 手动创建 `refs/remotes/origin/main` 和 `refs/remotes/origin/net10rebuild`
- **注意**：每次 fetch/push 后都需���重建 refs，这是该版本 Git 的已知 bug
